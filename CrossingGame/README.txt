A simple Turtle Crossing game built with Python, inspired by classic road-crossing games. 
The player controls a turtle and tries to cross a busy road while avoiding moving vehicles.

🎮 Features
Player-controlled turtle
Randomly generated moving cars
Increasing difficulty as the player progresses
Collision detection
Level progression
Score and level tracking
Game-over detection


🕹️ Controls
↑ — Move forward
↓ — Move backward


🛠️ Technologies Used
Python
Turtle Graphics
Object-Oriented Programming
Randomization
Collision Detection


▶️ How to Run
Make sure Python is installed, then run:
python main.py
